# Монтажна схема — 3D на телефона

Страницата отваря монтажната схема на панелите, записана от SketchUp с плъгина
**MN Assembly**: всеки панел е плътен блок в свой цвят, с име и номер на поставяне.

- **Линк за модел:** `https://<потребител>.github.io/<хранилище>/?m=<име>` отваря `models/<име>.glb`.
- **Файл от телефона:** бутонът 📂 отваря `.glb`, пратен например по Viber.
- **Въртене:** с пръст; приближаване — с два пръста; цъкане на панел — името и номерът му.
- **2D:** етажите отгоре; пръстът мести, два пръста приближават; същите етапи и стъпки.
- **Етапи:** къщичките отляво — Етаж 1 · Под · Етаж 2 · Покрив; всяка показва своя етап и всичко под него.
- **Стъпки:** моделът се отваря на 0; ◀ ▶ и плъзгачът добавят и махат по един панел по реда на монтажа.

Пример: `?m=sample`.

Изходният код е в проекта MN Production Suite (`plugins/mn-assembly-scheme/viewer/`).
Моделите в `models/` се качват от SketchUp с бутона **Send to the phone**.
